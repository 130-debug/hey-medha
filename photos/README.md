# Photos

Drop your photos here and reference them in `index.html`:

- `medha.jpg` — Hero section (her photo)
- `us.jpg` — Featured couple photo (wide)
- `photo2.jpg` — Fun moment
- `photo3.jpg` — Pretty pic
- `photo4.jpg` — Late night memory
- `photo5.jpg` — Normal cute day

Then replace the placeholder `<div class="ph">` blocks in index.html with:

```html
<img src="photos/medha.jpg" alt="Medha" />
```
